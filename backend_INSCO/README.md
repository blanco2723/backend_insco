# Sistema Web para la Descolonización Curricular del INSCO

## Descripción

Sistema web desarrollado para apoyar la descolonización curricular mediante la articulación de saberes técnicos, tecnológicos y comunitarios en la Carrera de Sistemas Informáticos del Instituto INSCO.

## Tecnologías

- Node.js
- Express
- Supabase
- PostgreSQL
- JWT
- Bootstrap
- JavaScript

## Módulos

- Autenticación
- Usuarios
- Saberes Comunitarios
- Contenidos Curriculares
- Articulaciones Curriculares
- Reportes
